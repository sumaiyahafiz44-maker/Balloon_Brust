## About The Game

**Balloon Burst** is a fun, colorful, and interactive 2D arcade game developed using Python and Pygame.

In this game, colorful balloons appear on the screen and move upward. Players use their mouse to click and burst the balloons to earn points.

The main objective is to burst as many balloons as possible before the time runs out.

##  Key Features

-  **Colorful Balloons:** Different colorful balloons appear on the screen.
-  **Mouse Interaction:** Click on balloons to burst them.
-  **Score System:** Earn points for every successful balloon pop.
-  **Countdown Timer:** Play within a limited time.
-  **Pop Animation:** Enjoy balloon bursting effects.
-  **Attractive Graphics:** Colorful and eye-catching game design.
-  **Restart Option:** Restart the game and play again.
-  **Game Over Screen:** View your final score.

## How To Play

1. Start the game.
2. Wait for colorful balloons to appear.
3. Use your mouse to click on the balloons.
4. Each successful click increases your score.
5. Try to pop as many balloons as possible.
6. Beat the timer and achieve a high score!
7. Restart the game and enjoy playing again.

###  Game Controls

| Controls | Actions |
|---|---|
| Left Mouse Click | Burst a balloon |
| Restart Button | Start a new game |
| Close Button | Exit the game |
